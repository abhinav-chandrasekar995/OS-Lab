# Operating Systems Lab

Laboratory programs completed as part of the **Operating Systems Lab** course (**23CS4PCOPS**).

## Course Information

| Field | Details |
|-------|---------|
| Course | Operating Systems Lab |
| Course Code | 23CS4PCOPS |
| Language | C |
| Compiler | GCC |

## Overview

This repository contains implementations of Operating Systems laboratory experiments covering core concepts such as:

- CPU Scheduling
- Process Synchronization
- Deadlocks
- Memory Management
- Page Replacement
- Disk Scheduling
- System Calls
- Multithreading

## Programs

- FCFS Scheduling
- SJF Scheduling
- Priority Scheduling
- Round Robin Scheduling
- Producer–Consumer Problem
- Dining Philosophers Problem
- Readers–Writers Problem
- Semaphores
- Banker's Algorithm
- Deadlock Detection
- First Fit, Best Fit and Worst Fit Memory Allocation
- FIFO, LRU and Optimal Page Replacement
- Disk Scheduling Algorithms
- System Calls
- POSIX Threads

## Compilation

Compile a program using GCC:

```bash
gcc filename.c -o output
./output
```

For programs using POSIX threads:

```bash
gcc filename.c -pthread -o output
./output
```
